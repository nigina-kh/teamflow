# TeamFlow

A modern full-stack project management platform inspired by Jira and Linear.

## Tech Stack

### Frontend

- Angular
- TypeScript
- SCSS

### Backend

- NestJS
- Prisma
- PostgreSQL

## Features

- Authentication
- Workspaces
- Projects
- Kanban Boards
- Tasks
- Comments
- Attachments
- Dashboard
- Notifications
