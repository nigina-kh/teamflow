# Workspace Roles

## Owner

The highest level of access within a workspace.

Permissions:

- Create workspace
- Update workspace
- Delete workspace
- Transfer ownership
- Invite members
- Remove members
- Manage roles
- Create projects
- Archive projects
- Delete projects
- Full access to all boards and tasks

---

## Admin

Manages the workspace but cannot delete it.

Permissions:

- Invite members
- Manage projects
- Manage boards
- Manage tasks
- Manage labels
- View analytics

---

## Member

Regular workspace participant.

Permissions:

- View projects
- Create tasks
- Edit assigned tasks
- Comment on tasks
- Move tasks between statuses

---

## Guest

Limited read-only access.

Permissions:

- View projects
- View boards
- View tasks
- View comments
- Cannot create or edit content
